# macOS 빌드 관련 안내

안녕하세요, AIChatConsole 개발자입니다!

현재 AIChatConsole의 macOS 버전을 제공하기 위해 노력하고 있습니다.

다만 개발 환경상 제가 현재 Mac을 보유하고 있지 않아 실제 macOS 기기에서 애플리케이션을 직접 빌드하거나 테스트하기 어려운 상황입니다.

따라서 macOS 사용자 여러분께 양해를 부탁드립니다.

현재 다음과 같은 작업을 진행하고자 합니다.

- Apple Silicon(M1, M2, M3, M4 등) 지원
- Intel 기반 Mac 지원
- .NET Runtime이 포함된 독립 실행형(Self-contained) 빌드 제공
- macOS 환경에서의 호환성 및 안정성 테스트

macOS 기기를 보유하신 사용자분들의 테스트 참여와 버그 제보를 환영합니다.

아직 충분히 검증되지 않은 macOS 빌드는 실험적(Experimental) 버전으로 제공할 수 있습니다.

불편을 드려 죄송하며, 여러분의 이해와 도움에 감사드립니다.

**AIChatConsole을 더 나은 프로젝트로 만들어 나가겠습니다!**

감사합니다. ❤️
